Повнофункціональний, автономний апаратно-програмний емулятор акумуляторних систем керування (BMS) на базі мікроконтролера **ESP32-C6** (також підтримується **ESP32-S3**). 

Емулятор реалізує **подвійний протокольний стек** (Dual-Protocol Engine) і здатний на льоту повністю імітувати роботу двох найпопулярніших у світі стандартів BMS:
1. **JBD / Xiaoxiang / Jiabaida / Overkill Solar BMS**
2. **Daly Smart BMS (DL-xxxx)**

Проєкт розроблено для швидкого тестування, калібрування діагностичних шлюзів (ESP32 Universal Monitor / Tailscale Probe), інверторів (Growatt, Deye, Datouboss, Sandisolar, Victron), систем автоматизації Home Assistant / ESPHome та перевірки офіційних мобільних додатків без необхідності підключення до небезпечної високовольтної акумуляторної батареї.

> 📘 **Повний технічний опис усіх реалізованих функцій, протоколів і регістрів доступний у файлі [PROJECT_CAPABILITIES.md](PROJECT_CAPABILITIES.md).**

## 🚀 Основні можливості

### 1. Подвійний протокольний стек (JBD ↔ Daly)
- **Перемикання на льоту**:
  - **Апаратний Double Reset**: подвійне швидке натискання кнопки **RST** на платі (< 1.5 с) перемикає протокол між JBD та Daly. Стан зберігається в енергонезалежній пам'яті NVS Flash і зберігається після перезавантаження.
  - **Serial CLI**: команди `m` (перемикання), `j` (JBD), `y` (Daly) у моніторі порту (115200 baud).
  - **Скрипт**: `./switch_mode.sh daly` або `./switch_mode.sh jbd`.
- **Автоматична зміна BLE-ідентичності**:
  - При перемиканні режиму автоматично оновлюється ім'я пристрою, сервіси GATT, характеристики та апаратна MAC-адреса.

---

### 2. Емуляція Daly Smart BMS (DL-401804015491)
- **Ім'я пристрою**: `DL-401804015491` | **MAC**: `A5:C2:3A:26:F2:D1`.
- **Підтримка двох стандартів зв'язку Daly**:
  1. **Modbus RTU over BLE (0xD2)**: для офіційного мобільного додатку **Smart BMS** (iOS та Android).
     - Повне відображення всіх 8 комірок (3.275–3.288 В) з кольоровою підсвіткою min/max.
     - Температури NTC (T1, T2, T3) та температура силіційових ключів МОП (28°C).
     - Повна ідентифікація: версія ПЗ `24_231116_001T`, модель `DL-8S-200A`, серійний номер `207JD160400278`, дата виробництва `20240516` (0x00CC), PID `NoPID` (0x00CE).
     - Керування ключами заряду/розряду (Func 0x06: Charge MOS `0x00A5`, Discharge MOS `0x00A6`, активний балансир `0x00A7`).
  2. **UART-over-BLE (0xA5)**: 13-байтний фреймовий протокол для **Universal BMS Diagnostic Monitor (ESP32-S3 Probe / Tailscale)**, драйверів ESPHome та інверторів.
     - Команди `0x90`–`0x98`, `0xD9`/`0xDA`.
     - Надійна послідовна передача 3 фреймів напруг комірок (`0x95`) з міжкадровим інтервалом 40 мс без затирання BLE буфера.

---

### 3. Емуляція JBD / Xiaoxiang BMS (BS-26A-072-005)
- **Ім'я пристрою**: `BS-26A-072-005` | **MAC**: `A5:C2:3A:26:F2:C2`.
- **Сумісність з додатками**: офіційний **JBD BMS** (iOS / Android) та **Xiaoxiang BMS**.
- **Повна підтримка сервісів**:
  - Головний сервіс `0xFF00` (Notify: `0xFF01`, Write: `0xFF02`) та дзеркальний `0xFFF0`.
  - **iOS CoreBluetooth Fix**: інжекція апаратного MAC у `Manufacturer Data` Scan Response для миттєвого пошуку додатком на iPhone.
  - **Авторизація**: підтримка хендшейку `FF AA 15` та перевірки пароля `123456`.
  - **Пам'ять та налаштування**: повна карта EEPROM `0x10`..`0x3F`, `0xAA` та підтримка читання прямої пам'яті AFE RAM `0xFA` (зсув `0x58`) для Android.
  - **20-байтове ATT MTU чанкування**: нарізка відповідей по 20 байт із затримкою 25 мс для стабільної роботи на Android (MTU 23) та iOS (MTU 512).

---

### 4. Фізичний рушій батареї 8S LiFePO4 (24V)
- **Живе «дихання» комірок**: напруги комірок плавно коливаються у діапазоні $3.275\text{–}3.288\text{ В}$ (дельта $3\text{–}12\text{ мВ}$) за синусоїдальним законом із псевдовипадковим мікро-шумом.
- **Режими навантаження**:
  - **Розряд (Discharge)**: струм $-17.00\text{ А}$, напруга $\sim 26.24\text{ В}$, вихідна потужність $\sim 445\text{ Вт}$.
  - **Заряд (Charge)**: струм $+17.00\text{ А}$, напруга $\sim 27.20\text{ В}$.
  - **Спокій (Standby)**: струм $0.00\text{ А}$, потужність $0\text{ Вт}$.
- **Coulomb Counting**: безперервний підрахунок ємності ($I \times \Delta t$) у режимі реального часу з динамічним оновленням SOC (%).
- **Реагування на тумблери FET**: при вимкненні Discharge FET навантаження миттєво відключається ($0\text{ А}$, $0\text{ Вт}$).

---

### 5. Апаратна індикація (WS2812B RGB LED @ GPIO 8)
- 🔴 **Червоний**: Очікування підключення клієнта (BLE Advertising).
- 🟠 **Помаранчевий**: Активний розряд під навантаженням (Discharge, $-17\text{ А}$).
- 🩵 **Блакитний (Cyan)**: Активний заряд батареї (Charge, $+17\text{ А}$).
- 🟢 **Зелений**: Спокій / Standby ($0\text{ А}$, ключі замкнено).
- ⚪ **Білий**: Повний заряд ($100\%\text{ SOC}$).
- 🟡 **Жовтий**: Спрацювання захисту або симуляція аварії.

## ⚡ Збірка та прошивка через PlatformIO

### 1. Прошивка ESP32-C6:
```bash
pio run -e esp32-c6-supermini -t upload
```

### 2. Прошивка ESP32-S3:
```bash
pio run -e esp32-s3-supermini -t upload
```

### 3. Швидка прошивка готового Factory бінарника через esptool (0x0000):
```bash
esptool.py -p /dev/cu.usbmodem* -b 921600 write_flash 0x0000 bin/jbd_emulator_esp32_c6_factory.bin
```

## 💻 Інтерактивні команди в Serial Terminal (115200 baud)

- `m` або `M`: Перемкнути протокол (**JBD** $\leftrightarrow$ **DALY**).
- `j` або `J`: Примусово встановити режим **JBD BMS**.
- `y` або `Y`: Примусово встановити режим **DALY BMS**.
- `1` або `d`: Режим активного розряду ($-17.00\text{ А}$) $\to$ 🟠 Помаранчевий LED.
- `2` або `c`: Режим активного заряду ($+17.00\text{ А}$) $\to$ 🩵 Блакитний LED.
- `0` або `s`: Режим спокою ($0.00\text{ А}$) $\to$ 🟢 Зелений LED.
- `b` або `B`: Увімкнути/вимкнути активне балансування.
- `f` або `F`: Перемкнути ключі Charge/Discharge FET.
- `+` / `-`: Збільшити / зменшити рівень заряду SOC на $\pm 5\%$.
- `t` або `T`: Примусовий залп повної телеметрії в BLE.
- `?` або `h`: Довідка по командах.

## 📱 Перевірена сумісність з клієнтами

1. **JBD BMS / Xiaoxiang App** (iOS & Android) — підключення в режимі JBD (`BS-26A-072-005`).
2. **Smart BMS App** (iOS & Android) — підключення в режимі Daly (`DL-401804015491`), повні 8 комірок і керування FET.
3. **Universal BMS Diagnostic Monitor** (ESP32-S3 Probe через Tailscale) — автовизначення обох типів BMS (JBD та Daly).
4. **ESPHome / Home Assistant** — інтеграція через стандартні компоненти `daly_bms` та `jbd_bms`.
