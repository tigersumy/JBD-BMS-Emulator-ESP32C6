---

Повнофункціональний апаратно-програмний автономний емулятор акумуляторної системи керування **JBD (Xiaoxiang / Jiabaida / DB24SF01 / 8S200A / Overkill Solar) BMS** на базі мікроконтролера **ESP32-C6** (також підтримується **ESP32-S3**).

Проєкт розроблено для тестування, калібрування, налагодження шлюзів інверторів, сонячних систем та перевірки мобільних додатків без необхідності підключення до фізичної високовольтної / силової акумуляторної збірки.

---

## 🚀 Основні можливості

- **Сумісність з мобільними додатками**:
  - **Xiaoxiang BMS** (iOS / Android)
  - **SMART BMS** (iOS / Android)
  - **BMS Tool** / **ESPHome JBD BMS** / **ESP32 Universal Monitor**
- **Повна емуляція GATT BLE Сервісів**:
  - Service UUID: `0000FF00-0000-1000-8000-00805F9B34FB` (`0xFF00`)
  - Notify/Read UUID: `0000FF01-0000-1000-8000-00805F9B34FB` (`0xFF01`)
  - Write UUID: `0000FF02-0000-1000-8000-00805F9B34FB` (`0xFF02`)
- **Профіль BMS за замовчуванням (DB24SF01 V1.0 / 8S200A)**:
  - Ім'я BLE: `DB24SF01`
  - Виробник (Регістр `0xA1`): `8S200A`
  - Модель плати (Регістр `0xA2`): `DB24SF01 V1.0`
  - Версія прошивки (Регістр `0x03` байт 18): `13`
  - Номінальна ємність: `200.00 Ah` (8S LiFePO4 24V)
  - Залишкова ємність: `194.00 Ah` (97% SOC)
- **Реалістична телеметрія 8S LiFePO4 з фізичним рушієм**:
  - Струм навантаження: **`-17.00 А`** (з реалістичним jitter $\pm 0.1\text{А}$)
  - Споживана потужність: **`~447 Вт`** ($26.24\text{ В} \times 17.0\text{ А}$)
  - Напруга батареї під навантаженням: **`~26.24 В`** (~`3.28 В` на комірку)
  - Плавний підрахунок ампер-годин (Coulomb Counting): $I \times \Delta t$
  - Відключення струму (0A / 0W) при розмиканні тумблера **Discharge FET**
  - Напруги 8-ми окремих комірок (3278–3284 мВ під навантаженням)
  - Температури NTC1 / NTC2: 26.0 °C / 25.5 °C під струмом
- **Апаратна RGB-індикація (WS2812B на GPIO 8)**:
  - 🔴 **Червоний**: Режим очікування підключення (Advertising).
  - 🟠 **Помаранчевий**: Активний розряд (-17.00 A).
  - 🩵 **Блакитний (Cyan)**: Активний заряд (+17.00 A).
  - 🟢 **Зелений**: Спокій / Standby (0.00 A / ключі вимкнено).
  - ⚪ **Білий**: Повний заряд (100% SOC).
  - 🟡 **Жовтий**: Аварія / Спрацювання захисту (`0x10 != 0`).
  - *Яскравість світлодіода оптимізовано на 50% для комфортної роботи.*
- **Неблокуючий USB-CDC інтерфейс**:
  - Завдяки `Serial.setTxTimeoutMs(0)` та виклику `notify()` у пріоритеті, емулятор працює на максимальній швидкості автономно, незалежно від наявності відкритого монітора порту на ПК.

## ⚡ Збірка та прошивка через PlatformIO

### 1. Прошивка ESP32-C6:
```bash
pio run -e esp32-c6-supermini -t upload
```

### 2. Прошивка ESP32-S3:
```bash
pio run -e esp32-s3-supermini -t upload
```

### 3. Швидка прошивка готового Factory бінарника через esptool (0x0000):
```bash
esptool.py -p /dev/cu.usbmodem* -b 921600 write_flash 0x0000 bin/jbd_emulator_esp32_c6_factory.bin
```

## 💻 Інтерактивні команди в Serial Terminal (115200 baud)

- `1` або `d`: Режим активного розряду (-17.00 A) $\to$ 🟠 Помаранчевий LED.
- `2` або `g`: Режим активного заряду (+17.00 A) $\to$ 🩵 Блакитний LED.
- `0` або `i`: Режим спокою (0.00 A) $\to$ 🟢 Зелений LED.
- `t`: Перемкнути між Зарядом та Розрядом.
- `+` / `=`: Збільшити SOC на +1%.
- `-` / `_`: Зменшити SOC на -1%.

## 📱 Підключення через мобільні додатки

1. Увімкніть Bluetooth на iPhone або Android.
2. Відкрийте додаток **Xiaoxiang BMS** або **SMART BMS**.
3. У списку доступних пристроїв виберіть **`DB24SF01`**.
4. Спостерігайте миттєве відображення 8 осередків, 26.24V, 17A, дельти напруг та керуйте ключами заряду/розряду.
