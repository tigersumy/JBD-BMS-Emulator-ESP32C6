Повнофункціональний, автономний апаратно-програмний емулятор акумуляторних систем керування (BMS) на базі мікроконтролера **ESP32-C6** (також підтримується **ESP32-S3**). 

Емулятор реалізує **подвійний протокольний стек** (Dual-Protocol Engine) і здатний на льоту повністю імітувати роботу двох найпопулярніших у світі стандартів BMS:
1. **Daly Smart BMS (DL-xxxx)**
2. **JBD / Xiaoxiang / Jiabaida / Overkill Solar BMS**

Проєкт розроблено для швидкого тестування, калібрування діагностичних шлюзів (ESP32 Universal Monitor / Tailscale Probe), інверторів (Growatt, Deye, Datouboss, Sandisolar, Victron), систем автоматизації Home Assistant / ESPHome та перевірки офіційних мобільних додатків без необхідності підключення до небезпечної високовольтної акумуляторної батареї.

> 📘 **Повний технічний опис усіх реалізованих функцій, протоколів і регістрів доступний у файлі [PROJECT_CAPABILITIES.md](PROJECT_CAPABILITIES.md).**

## 🚀 Основні можливості (Key Features)

### 📱 Сумісність з мобільними додатками та системами (Mobile App & Client Compatibility)
- **Smart BMS (Офіційний мобільний додаток Daly BMS для iOS та Android)**:
  - **100% сумісність у режимі Daly BMS (`DL-401804015491`)**.
  - Повне відображення всіх 8 комірок батареї (3.275–3.288 В) з кольоровою підсвіткою мінімальної та максимальної напруги.
  - Повна системна ідентифікація: версія ПЗ `24_231116_001T`, модель `DL-8S-200A`, серійний номер `207JD160400278`, дата виробництва `20240516`, PID `NoPID`.
  - Керування ключами заряду та розряду (Charge / Discharge MOS) та активним балансиром безпосередньо з інтерфейсу додатку.
- **JBD BMS (Офіційний мобільний додаток Jiabaida для iOS та Android)**:
  - **100% сумісність у режимі JBD BMS (`BS-26A-072-005`)**.
  - Повна підтримка фірмової PIN-авторизації `FF AA 15` (пароль за замовчуванням `123456`) та хендшейку.
  - Робота з вкладками «Параметри» та «Про батарею» (читання та запис регістрів EEPROM).
- **Xiaoxiang BMS (iOS та Android)**:
  - Підтримка моніторингу телеметрії, напруг комірок та температур у режимі JBD.
- **Universal BMS Diagnostic Monitor (ESP32-S3 Probe / Tailscale Web Dashboard)**:
  - Автоматичне розпізнавання обох типів BMS (і Daly, і JBD) з передачею телеметрії в реальному часі через VPN Tailscale.
- **ESPHome / Home Assistant / Node-RED / Шлюзи інверторів**:
  - Нативна сумісність зі стандартними компонентами `daly_bms` та `jbd_bms`.

### 🔄 Подвійний протокольний стек (Dual-Protocol Architecture)
- **Миттєве перемикання між JBD та Daly**:
  - **Апаратний Double Reset**: подвійне швидке натискання кнопки **RST** на платі (< 1.5 с) перемикає активний протокол. Вибір зберігається в енергонезалежній пам'яті NVS Flash.
  - **Serial CLI**: інтерактивні команди `m` (перемикання), `j` (JBD), `y` (Daly) у моніторі порту (115200 baud).
  - **Скрипт**: швидке перемикання через `./switch_mode.sh daly` або `./switch_mode.sh jbd`.
- **Динамічна зміна BLE-ідентичності**:
  - При перемиканні автоматично змінюється ім'я Bluetooth, GATT-сервіси, характеристики та апаратна MAC-адреса.

### 🛡️ Емуляція Daly Smart BMS (DL-401804015491)
- **Ім'я пристрою**: `DL-401804015491` | **Апаратний MAC**: `A5:C2:3A:26:F2:D1`.
- **Підтримка двох незалежних протоколів Daly**:
  1. **Modbus RTU over BLE (`0xD2`)** — для офіційного мобільного додатку **Smart BMS**:
     - Функція 0x03 (Read Holding Registers): динамічний зріз до 80 регістрів.
     - Регістри `0x0000..0x001F`: напруги комірок 1..32 (мВ).
     - Регістри `0x0020..0x0027`: температури NTC 1..8 (зі зміщенням $+40^\circ\text{C}$).
     - Регістри `0x0028..0x0046`: напруга пакета ($0.1\text{ В}$), струм (зсув $30000$), SOC, min/max V та T, середня напруга, дельта, циклічність, потужність у Вт.
     - Регістри `0x0047..0x0056`: дзеркальний блок окремих комірок (Single Cell Voltages 1..16).
     - Регістри `0x0080..0x00A8`: конфігурація та пороги захистів.
     - Регістри `0x00A9..0x00CC` (35 регістрів = 70 байт): ідентифікація пристрою (SW `24_231116_001T`, HW `DL-8S-200A`, SN `207JD160400278`, пароль `123456`).
     - Регістри `0x00CC..0x00CD`: дата виробництва (`20240516`).
     - Регістри `0x00CE..0x00D0`: PID пристрою (`NoPID`).
     - Функція 0x06 (Write Single Register): керування ключами Charge MOS (`0x00A5`), Discharge MOS (`0x00A6`) та балансиром (`0x00A7`).
  2. **UART-over-BLE (`0xA5`)** — 13-байтний фреймовий протокол для діагностичних зондів та інверторів:
     - Команди `0x90`–`0x98`, `0xD9`/`0xDA`.
     - Надійна послідовна передача 3 фреймів напруг комірок (`0x95`) з міжкадровим інтервалом 40 мс без затирання BLE буфера.

### ⚡ Емуляція JBD / Xiaoxiang BMS (BS-26A-072-005)
- **Ім'я пристрою**: `BS-26A-072-005` | **Апаратний MAC**: `A5:C2:3A:26:F2:C2`.
- **Сервіси GATT**: головний сервіс `0xFF00` (Notify: `0xFF01`, Write: `0xFF02`) та дзеркальний `0xFFF0`.
- **Сумісність з Apple iOS CoreBluetooth**:
  - Вкладання апаратного MAC у `Manufacturer Data` Scan Response для миттєвого пошуку додатком на iPhone.
  - Режим Open Pairing з автентифікацією на рівні протоколу JBD (`123456`) без конфліктів системного спарювання iOS SMP.
- **Пам'ять та налаштування**:
  - Повна карта регістрів EEPROM `0x10`..`0x3F`, `0xAA` (ємність, цикли, пороги захисту).
  - Підтримка читання прямої пам'яті AFE RAM `0xFA` (зсув `0x58` — напруги 8 комірок у мВ) для Android JBD App.
  - Чанкування відповідей по $\le 20$ байт (ATT MTU 23–512) із затримкою 25 мс для 100% стабільності передачі.

### 🔋 Фізичний рушій батареї та конфігурації 4S / 8S / 16S ... 32S
- **Підтримка різноманітних акумуляторних конфігурацій**:
  - **4S (12V / 12.8V LiFePO4)**:
    - Робочий діапазон: $10.0\text{ В} \dots 14.6\text{ В}$ (номінал $12.8\text{ В}$).
    - Призначення: автомобільні, човнові та кемпінгові системи, портативні зарядні станції, 12V UPS.
    - Готовий калібрувальний файл: `4s standard LiFePO4 Alf-20210608.fig`.
    - Версія ПЗ Daly: `12_231116_001T` | JBD модель: `JBD-SP04S020` / `DP04S007`.
  - **8S (24V / 25.6V LiFePO4) — Базова конфігурація за замовчуванням (Default)**:
    - Робочий діапазон: $20.0\text{ В} \dots 29.2\text{ В}$ (номінал $25.6\text{ В}$, робоча точка під навантаженням $17\text{ А}$ $\sim 26.24\text{ В}$, потужність $\sim 445\text{ Вт}$).
    - Призначення: домашні ДБЖ, сонячні станції 24V, телеком-живлення.
    - Готовий калібрувальний файл: `8s standard LiFePO4 Alf-20210608.fig`.
    - Ідентифікація: Daly `DL-8S-200A` (`24_231116_001T`) | JBD `DB24SF01 V1.0` / `BS-26A-072-005`.
  - **16S (48V / 51.2V LiFePO4)**:
    - Робочий діапазон: $40.0\text{ В} \dots 58.4\text{ В}$ (номінал $51.2\text{ В}$).
    - Призначення: промисловий та побутовий стандарт для 48V сонячних інверторів (Deye, Growatt, Victron, Must, Axioma, Luxpower) та серверних акумуляторів (Server Rack Battery).
    - Готовий калібрувальний файл: `16s standard LiFePO4 Alf-20210608.fig`.
  - **Універсальний динамічний діапазон від 3S до 32S**:
    - Повна підтримка довільної кількості комірок у протоколах JBD (регістр `0x2F`) та Daly (регістри `0x0031`/`0x0083`, команди `0x50`/`0xD6`).
    - Модуль розрахунку напруг динамічно масштабує напругу всього пакета залежно від заданої кількості комірок: $U_{pack} = \sum_{i=1}^{N} U_{cell\_i}$.
- **Підтримувані типи електрохімії**:
  - **LiFePO4 (LFP)**: $3.2\text{ В}$ номінал ($2.5\text{ В} \dots 3.65\text{ В}$). Конфігурації: 4S (12.8V), 8S (25.6V), 16S (51.2V).
  - **Li-ion / NMC (Ternary)**: $3.6\text{–}3.7\text{ В}$ номінал ($2.8\text{ В} \dots 4.2\text{ В}$). Конфігурації: 3S (11.1V), 7S (25.9V), 10S (36V), 13S/14S (48V), 20S (72V).
  - **LTO (Lithium Titanate)**: $2.3\text{–}2.4\text{ В}$ номінал ($1.5\text{ В} \dots 2.8\text{ В}$). Конфігурації: 5S/6S (12V), 10S/11S (24V), 20S/22S (48V).
- **Живе «дихання» комірок (Dynamic Cell Breathing)**: напруги комірок плавно коливаються за синусоїдальним законом із псевдовипадковим мікро-шумом (дельта $3\text{–}12\text{ мВ}$).
- **Режими навантаження**:
  - **Розряд (Discharge)**: струм $-17.00\text{ А}$ (для 8S напруга $\sim 26.24\text{ В}$, вихідна потужність $\sim 445\text{ Вт}$).
  - **Заряд (Charge)**: струм $+25.00\text{ А}$ (динамічні пульсації зарядної кривої).
  - **Спокій (Standby)**: струм $0.00\text{ А}$, потужність $0\text{ Вт}$.
- **Coulomb Counting**: безперервний інтегральний підрахунок ємності ($I \times \Delta t$) у режимі реального часу з динамічним оновленням SOC (%).
- **Реагування на тумблери FET**: при вимкненні Discharge FET навантаження миттєво відключається ($0\text{ А}$, $0\text{ Вт}$).

### 🎨 Апаратна індикація (WS2812B RGB LED @ GPIO 8)
- 🔴 **Червоний**: Очікування підключення клієнта (BLE Advertising).
- 🟠 **Помаранчевий**: Активний розряд під навантаженням (Discharge, $-17\text{ А}$).
- 🩵 **Блакитний (Cyan)**: Активний заряд батареї (Charge, $+17\text{ А}$).
- 🟢 **Зелений**: Спокій / Standby ($0\text{ А}$, ключі замкнено).
- ⚪ **Білий**: Повний заряд ($100\%\text{ SOC}$).
- 🟡 **Жовтий**: Спрацювання захисту або симуляція аварії.

### 1. Прошивка ESP32-C6:
```bash
pio run -e esp32-c6-supermini -t upload
```

### 2. Прошивка ESP32-S3:

## 💻 Інтерактивні команди в Serial Terminal (115200 baud)

- `m` або `M`: Перемкнути протокол (**JBD** $\leftrightarrow$ **DALY**).
- `j` або `J`: Примусово встановити режим **JBD BMS**.
- `y` або `Y`: Примусово встановити режим **DALY BMS**.
- `1` або `d`: Режим активного розряду ($-17.00\text{ А}$) $\to$ 🟠 Помаранчевий LED.
- `2` або `c`: Режим активного заряду ($+17.00\text{ А}$) $\to$ 🩵 Блакитний LED.
- `0` або `s`: Режим спокою ($0.00\text{ А}$) $\to$ 🟢 Зелений LED.
- `b` або `B`: Увімкнути/вимкнути активне балансування.
- `f` або `F`: Перемкнути ключі Charge/Discharge FET.
- `+` / `-`: Збільшити / зменшити рівень заряду SOC на $\pm 5\%$.
- `t` або `T`: Примусовий залп повної телеметрії в BLE.
- `?` або `h`: Довідка по командах.

## 📱 Перевірена сумісність з клієнтами

1. **Smart BMS App** (iOS & Android) — підключення в режимі Daly (`DL-401804015491`), повні 8 комірок, версія ПЗ, серійний номер, дати та керування FET.
2. **JBD BMS / Xiaoxiang App** (iOS & Android) — підключення в режимі JBD (`BS-26A-072-005`), повна телеметрія, EEPROM і PIN-авторизація.
3. **Universal BMS Diagnostic Monitor** (ESP32-S3 Probe через Tailscale) — автовизначення обох типів BMS (JBD та Daly).
4. **ESPHome / Home Assistant** — інтеграція через стандартні компоненти `daly_bms` та `jbd_bms`.
